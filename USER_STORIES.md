## 🧾 User Stories – Functional Expectations

### 🧑‍🎓 Aspirant

- As an aspirant, I want to register online so that I can apply for admission.
- As an aspirant, I want to submit an application form so that I can be considered for admission.
- As an aspirant, I want to track my application status so that I know when I’m accepted or rejected.

### 🎓 Student

- As a student, I want to view my results so that I can monitor my academic performance.
- As a student, I want to check my fee status so that I know if I’m financially cleared.
- As a student, I want to update my contact information to keep my records current.

### 👨‍🏫 Academic Staff

- As an academic staff member, I want to see my assigned courses so that I know what to teach.
- As an academic staff member, I want to enter and update student results to maintain academic records.
- As an academic staff member, I want to view student lists for my courses so that I can advise and grade them.

### 🧑‍💼 Non-Academic Staff

- As a non-academic staff member, I want to access student fee records to track payments.
- As a non-academic staff member, I want to review applications to assist the admissions process.

### 👩‍💼 Admin

- As an admin, I want to manage all academic structures so that the system reflects the real institution.
- As an admin, I want to promote aspirants to students to formalize admissions.
- As an admin, I want to manage calendars and results to maintain institutional order and performance tracking.
